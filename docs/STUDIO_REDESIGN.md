# Персонажи и гардероб: студийное оформление

Основные проблемы прежнего оформления: одинаковый характер материалов у разных костюмов,
маленькие цветовые карточки вместо изображений, перегруженный каталог при первом открытии
и слабая связь между выбранным персонажем и экраном финиша. Отдельно обнаружена утечка
собственных материалов при смене некоторых образов.

## Что изменилось

- Базовая модель получила более плавный силуэт, объёмные перчатки с большими пальцами,
  подошвы, окантовку лица и блики в глазах.
- Четыре существующих костюма переработаны: астронавт, ретро-робот, лунный кот и король
  пончиков. У каждого своя фурнитура, обувь и поверхность, реагирующая на свет.
- Первый экран гардероба показывает классику и четыре проработанных образа. Весь каталог,
  сохранённые образы, коллекции, эмоции и условия получения остаются доступны.
- В гардероб можно войти прямо из главного меню. Примерка открывается лицом к камере;
  доступны перетаскивание, стрелки, Home и включаемое автовращение.
- Карточки показывают реальные миниатюры 3D-моделей. Поиск, фильтры и отдельная панель
  действий позволяют примерять закрытые предметы и видеть условия получения.
- Меню, HUD, шкаф и финиш используют согласованные глубокие панели, световые грани,
  мятные акценты и золотые основные кнопки. На большом экране финиш показывает надетого
  персонажа на отдельной сцене; на узком экране место остаётся для результата и действий.

## Устройство и ограничения

`CharacterSurface.js` создаёт пять общих периодических normal map размером 128 × 128.
Они задают мелкий рельеф ткани, керамики, металла, плюша и теста; новых загрузок текстур нет.
`SignatureCostumes.js` строит объёмные детали по полю `render.signature`. Остальные предметы
используют прежние фабрики. Цвет обуви и видимость базовой антенны задаются данными костюма;
надетый отдельно предмет головы сохраняет приоритет.

`CosmeticPreview` использует один WebGL-контекст для сцены и миниатюр. Миниатюры снимаются
с неподвижного манекена, поэтому не изменяют позу и одежду персонажа в примерке.
Кэш ограничен 96 изображениями. При закрытии освобождаются собственные геометрии,
материалы и обработчики; общие ресурсы остаются в кэше. Мелкая фурнитура отключается
на `simple`, а костюмы укладываются в проверяемый бюджет 20 000 треугольников на персонажа.
Пока гардероб закрывает меню, основная 3D-сцена не перерисовывается; после закрытия
отрисовка продолжается. Это экономит работу GPU при примерке.

Изменения касаются отображения. Размеры коллизий, управление, сетевая симуляция, ID предметов
и правила владения сохраняются. Оценка FPS на физических телефонах остаётся отдельной
проверкой: эмуляция мобильного экрана её не заменяет.

## Проверка

```bash
npm run preflight
npm run test:client
npx playwright test e2e/studio.spec.js e2e/solo.spec.js e2e/menu-polish.spec.js e2e/menu-ux.spec.js --project=chromium --project=mobile-chromium
```

`cosmeticRenderer.test.mjs` проверяет сборку каталога, геометрию, рельеф, детализацию и уборку
ресурсов. `studio.spec.js` проверяет настоящие миниатюры, устойчивость позы, доступность
панели действий, примерку закрытой одежды без экипировки, поиск, клавиатуру, повторное открытие
и жизненный цикл сцены результатов. Снимки гардероба и финиша прикладываются к результатам E2E.
